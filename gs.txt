// ฟังก์ชันสำหรับตรวจเช็คและสร้างชีตอัตโนมัติหากยังไม่มี
function initDatabase() {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  
  // ตรวจสอบและสร้างชีต Products
  const pSheet = ss.getSheetByName("Products");
  if (!pSheet) {
    const sheet = ss.insertSheet("Products");
    sheet.appendRow(["Product_ID", "Product_Name", "Unit", "Cost", "Price_A", "Price_B", "Price_C", "Category", "Note", "Image_URL", "Stock_Qty", "Product_Group", "Supplier", "Storage_Area"]);
    sheet.getRange("1:1").setFontWeight("bold").setBackground("#d9ead3");
  } else {
    const lastCol = pSheet.getLastColumn();
    if (lastCol < 11) pSheet.getRange(1, 11).setValue("Stock_Qty");
    if (lastCol < 12) pSheet.getRange(1, 12).setValue("Product_Group");

// ฟังก์ชันดึงข้อมูลทั้งหมดส่งไปให้ Frontend ในรูปแบบ JSON (ดึงจาก Firebase ก่อนเพื่อความเร็วสูงสุด)
function getAppData() {
  try {
    const products = getFirebaseData("appData/products") || [];
    const machines = getFirebaseData("appData/machines") || [];
    const mappings = getFirebaseData("mappings") || [];
    const settings = getFirebaseData("appData/settings") || { isShowPriceBForGuest: false, isShowPriceCForGuest: false };
    const manuals = getFirebaseData("appData/manuals") || [];
    const lots = getLotsFromJson();
    const allUsers = getUsersJSON();
    const approvers = allUsers.filter(u => !!u.canApprove).map(u => ({
      fullName: u.fullName || "",
      email: u.email || "",
      department: u.department || "",
      role: u.role || "User"
    }));

    if (products.length > 0 || machines.length > 0) {
      return {
        products: products,
        machines: machines,
        mappings: mappings,
        settings: settings,
        manuals: manuals,
        lots: lots,
        approvers: approvers
      };
    }
  } catch (e) {
    Logger.log("getAppData from Firebase failed, falling back to Sheets: " + e.toString());
  }
  
  return rebuildAndSaveAppDataJson();
}

// ฟังก์ชันอ่านข้อมูลจาก Google Sheets และ Drive JSON แล้วนำมารวมกัน ซิงค์ลง Drive และ Firebase
function rebuildAndSaveAppDataJson(throwError = false) {
  initDatabase();
  const ss = SpreadsheetApp.getActiveSpreadsheet() || SpreadsheetApp.openById(SPREADSHEET_ID);
  
  // ดึงข้อมูล Products
  const prodSheet = ss.getSheetByName("Products");
  const prodData = prodSheet.getDataRange().getValues();
  const products = [];
  if (prodData.length > 1) {
    for (let i = 1; i < prodData.length; i++) {
      let r = prodData[i];
      products.push({
        id: r[0], name: r[1], unit: r[2], cost: parseFloat(r[3]) || 0,
        price_a: parseFloat(r[4]) || 0, price_b: parseFloat(r[5]) || 0, price_c: parseFloat(r[6]) || 0,
        category: r[7], note: r[8], image_url: r[9],
        stock_qty: (r[10] !== undefined && r[10] !== "") ? parseFloat(r[10]) : 0,
        group: r[11] || "",
        supplier: r[12] || "",
        storage: r[13] || ""
      });
    }
  }

  // ดึงข้อมูล Machines
  const machSheet = ss.getSheetByName("Machines");
  const machData = machSheet.getDataRange().getValues();
  const machines = [];
  if (machData.length > 1) {
    for (let i = 1; i < machData.length; i++) {
      machines.push({ 
        id: machData[i][0], 
        name: machData[i][1], 
        image_url: machData[i][2] || '',
        cost: parseFloat(machData[i][3]) || 0,
        price_a: parseFloat(machData[i][4]) || 0,
        price_b: parseFloat(machData[i][5]) || 0,
        price_c: parseFloat(machData[i][6]) || 0,
        note: machData[i][7] || '',
        group: machData[i][8] || '',
        supplier: machData[i][9] || '',
        storage: machData[i][10] || ''
      });
    }
  }

  // ดึงข้อมูล Mapping จาก JSON ใน Google Drive
  let mappings = getMappingsFromJson();
  const machineIds = new Set(machines.map(m => String(m.id).trim()));
  const productIds = new Set(products.map(p => String(p.id).trim()));
  const initialMappingsLength = mappings.length;

  mappings = mappings.filter(m => {
    return machineIds.has(String(m.machine_id).trim()) && 
           productIds.has(String(m.product_id).trim());
  });
  if (mappings.length < initialMappingsLength) {
    try {
      saveMappingsToJson(mappings);
    } catch (e) {
      Logger.log("ไม่สามารถเซฟข้อมูลการจับคู่ที่กรองใหม่ได้: " + e.toString());
    }
  }

  // ดึงข้อมูล Settings
  const settingsSheet = ss.getSheetByName("Settings");
  const settings = { isShowPriceBForGuest: false, isShowPriceCForGuest: false };
  if (settingsSheet) {
    const settingsData = settingsSheet.getDataRange().getValues();
    if (settingsData.length > 1) {
      for (let i = 1; i < settingsData.length; i++) {
        let key = settingsData[i][0];
        let val = settingsData[i][1];
        if (key === "isShowPriceBForGuest") settings.isShowPriceBForGuest = (String(val).toLowerCase() === "true");
        if (key === "isShowPriceCForGuest") settings.isShowPriceCForGuest = (String(val).toLowerCase() === "true");
      }
    }
  }

  // ดึงข้อมูล Manuals
  const manSheet = ss.getSheetByName("Manuals");
  const manuals = [];
  if (manSheet) {
    const manData = manSheet.getDataRange().getValues();
    if (manData.length > 1) {
      for (let i = 1; i < manData.length; i++) {
        manuals.push({
          id: manData[i][0],
          title: manData[i][1],
          description: manData[i][2] || '',
          file_url: manData[i][3] || '',
          file_type: manData[i][4] || '',
          uploaded_at: manData[i][5] || ''
        });
      }
    }
  }

  // ดึงข้อมูลผู้อนุมัติที่มีสิทธิ์ (canApprove)
  let approvers = [];
  try {
    const allUsers = getUsersJSON();
    approvers = allUsers.filter(u => !!u.canApprove).map(u => ({
      fullName: u.fullName || "",
      email: u.email || "",
      department: u.department || "",
      role: u.role || "User"
    }));
  } catch (e) {
    Logger.log("ไม่สามารถดึงข้อมูลผู้อนุมัติได้: " + e.toString());
  }

  const appData = {
    products: products,
    machines: machines,
    mappings: mappings,
    settings: settings,
    manuals: manuals,
    lots: getLotsFromJson(),
    approvers: approvers
  };

  try {
    const folder = DriveApp.getFolderById(JSON_FOLDER_ID);
    const files = folder.getFilesByName("app_data.json");
    const content = JSON.stringify(appData);
    if (files.hasNext()) {
      const file = files.next();
      file.setContent(content);
    } else {
      folder.createFile("app_data.json", content, MimeType.PLAIN_TEXT);
    }
  } catch (e) {
    Logger.log("rebuildAndSaveAppDataJson error: " + e.toString());
  }

  // ซิงค์ข้อมูลไปยัง Firebase
  try {
    syncToFirebase(appData);
  } catch (e) {
    Logger.log("Firebase Sync error: " + e.toString());
    if (throwError) {
      throw new Error("Firebase Sync failed: " + e.message);
    }
  }

  return appData;
}

// ฟังก์ชันซิงค์ข้อมูลไปยัง Firebase Realtime Database
function syncToFirebase(appData) {
  if (!FIREBASE_URL || FIREBASE_URL === "") {
    Logger.log("Firebase URL is not configured.");
    return;
  }
  
  let baseUrl = FIREBASE_URL;
  if (baseUrl.charAt(baseUrl.length - 1) !== '/') {
    baseUrl += '/';
  }
  
  const requests = [
    {
      url: baseUrl + "appData.json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : ""),
      method: "put",
      contentType: "application/json",
      payload: JSON.stringify(appData),
      muteHttpExceptions: true
    },
    {
      url: baseUrl + "mappings.json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : ""),
      method: "put",
      contentType: "application/json",
      payload: JSON.stringify(appData.mappings || []),
      muteHttpExceptions: true
    },
    {
      url: baseUrl + "lots.json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : ""),
      method: "put",
      contentType: "application/json",
      payload: JSON.stringify(appData.lots || []),
      muteHttpExceptions: true
    },
    {
      url: baseUrl + "appData/lastUpdated.json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : ""),
      method: "put",
      contentType: "application/json",
      payload: JSON.stringify(Date.now()),
      muteHttpExceptions: true
    }
  ];
  
  const responses = UrlFetchApp.fetchAll(requests);
  for (let i = 0; i < responses.length; i++) {
    if (responses[i].getResponseCode() !== 200) {
      throw new Error("Failed to sync to Firebase: HTTP " + responses[i].getResponseCode() + " - " + responses[i].getContentText());
    }
  }
}

// ฟังก์ชันดึงข้อมูลจาก Firebase Realtime Database
function getFirebaseData(path) {
  if (!FIREBASE_URL || FIREBASE_URL === "") {
    throw new Error("FIREBASE_URL is not configured.");
  }
  let baseUrl = FIREBASE_URL;
  if (baseUrl.charAt(baseUrl.length - 1) !== '/') {
    baseUrl += '/';
  }
  const url = baseUrl + path + ".json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : "");
  const response = UrlFetchApp.fetch(url, { method: "get", muteHttpExceptions: true });
  if (response.getResponseCode() === 200) {
    return JSON.parse(response.getContentText());
  }
  return null;
}

// ฟังก์ชันบันทึกข้อมูลไปยัง Firebase Realtime Database
function setFirebaseData(path, data) {
  if (!FIREBASE_URL || FIREBASE_URL === "") {
    throw new Error("FIREBASE_URL is not configured.");
  }
  let baseUrl = FIREBASE_URL;
  if (baseUrl.charAt(baseUrl.length - 1) !== '/') {
    baseUrl += '/';
  }
  const url = baseUrl + path + ".json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : "");
  const options = {
    method: "put",
    contentType: "application/json",
    payload: JSON.stringify(data),
    muteHttpExceptions: true
  };
  const response = UrlFetchApp.fetch(url, options);
  if (response.getResponseCode() !== 200) {
    throw new Error("Failed to write to Firebase: " + response.getContentText());
  }
}

// ฟังก์ชันอัปเดตข้อมูลแบบหลายตำแหน่งพร้อมกันไปยัง Firebase (PATCH)
function patchFirebaseData(path, data) {
  if (!FIREBASE_URL || FIREBASE_URL === "") {
    throw new Error("FIREBASE_URL is not configured.");
  }
  let baseUrl = FIREBASE_URL;
  if (baseUrl.charAt(baseUrl.length - 1) !== '/') {
    baseUrl += '/';
  }
  const url = baseUrl + path + ".json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : "");
  const options = {
    method: "patch",
    contentType: "application/json",
    payload: JSON.stringify(data),
    muteHttpExceptions: true
  };
  const response = UrlFetchApp.fetch(url, options);
  if (response.getResponseCode() !== 200) {
    throw new Error("Failed to patch Firebase: " + response.getContentText());
  }
}

  try {

    const base64 = base64Data.split(',')[1] || base64Data;
    const decoded = Utilities.base64Decode(base64);
    const blob = Utilities.newBlob(decoded, "image/jpeg", fileName); 
    
    const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID);
    const file = folder.createFile(blob);
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    return 'https://lh3.googleusercontent.com/d/' + file.getId();
  } catch (e) {
    throw new Error("อัปโหลดรูปภาพล้มเหลว: " + e.message);
  }
}

// ฟังก์ชันคำนวณราคา 3 ระดับตามเงื่อนไข (ใช้กับอะไหล่)
function calculatePrices(cost) {
  const costNum = parseFloat(cost) || 0;
  return {
    price_a: costNum * 2.1,
    price_b: costNum * 1.7,
    price_c: costNum * 1.3
  };
}

// 7. เพิ่ม Mapping
function addMapping(data) {
  let productIds = Array.isArray(data.product_ids) ? data.product_ids : [data.product_id];
  let machineId = String(data.machine_id);
  
  let mappings = getMappingsFromJson();
  let isModified = false;
  for (let p = 0; p < productIds.length; p++) {
    let pid = String(productIds[p]);
    if(!pid) continue;
    let isDuplicate = mappings.some(m => String(m.product_id) === pid && String(m.machine_id) === machineId);
    if (!isDuplicate) {
      mappings.push({ product_id: pid, machine_id: machineId });
      isModified = true;
    }
  }
  
  if (isModified) {
    saveMappingsToJson(mappings);
  } else {
    throw new Error("รายการอะไหล่ที่เลือก ถูกจับคู่กับเครื่องจักรนี้อยู่แล้วทั้งหมด");
  }
}

// 8. ลบ Mapping
function deleteMapping(data) {
  let pid = String(data.product_id);
  let mid = String(data.machine_id);
  
  let mappings = getMappingsFromJson();
  let initialLength = mappings.length;
  mappings = mappings.filter(m => !(String(m.product_id) === pid && String(m.machine_id) === mid));
  if (mappings.length < initialLength) {
    saveMappingsToJson(mappings);
  } else {
    throw new Error("ไม่พบรายการจับคู่ที่ต้องการลบ");
  }
}

// ดึงข้อมูล Mapping จาก JSON
function getMappingsFromJson() {
  try {
    const folder = DriveApp.getFolderById(JSON_FOLDER_ID);
    const files = folder.getFilesByName("mappings.json");
    if (files.hasNext()) {
      const file = files.next();
      const content = file.getBlob().getDataAsString();
      return JSON.parse(content) || [];
    } else {
      const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
      const sheet = ss.getSheetByName("Mapping");
      let mappings = [];
      if (sheet) {
        const values = sheet.getDataRange().getValues();
        if (values.length > 1) {
          for (let i = 1; i < values.length; i++) {
            if (values[i][0] && values[i][1]) {
              mappings.push({ product_id: String(values[i][0]), machine_id: String(values[i][1]) });
            }
          }
        }
        saveMappingsToJson(mappings);
        try { sheet.setName("Mapping_Backup_" + new Date().getTime()); } catch(err) {}
      } else {
        saveMappingsToJson([]);
      }
      return mappings;
    }
  } catch (e) {
    Logger.log("getMappingsFromJson error: " + e.toString());
    return [];
  }
}

function migrateTransactionsToJson() {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const txSheet = ss.getSheetByName("Transactions");
  const txdSheet = ss.getSheetByName("Transaction_Details");
  
  if (!txSheet || !txdSheet) return [];
  
  const txValues = txSheet.getDataRange().getValues();
  const txdValues = txdSheet.getDataRange().getValues();
  const detailsMap = {};
  
  if (txdValues.length > 1) {
    for (let i = 1; i < txdValues.length; i++) {
      const r = txdValues[i];
      const txId = String(r[1]).trim();
      if (!detailsMap[txId]) detailsMap[txId] = [];
      detailsMap[txId].push({
        detail_id: r[0], product_id: r[2], qty: r[3], price: r[4], subtotal: r[5]
      });
    }
  }
  
  const transactions = [];
  if (txValues.length > 1) {
    for (let i = 1; i < txValues.length; i++) {
      const r = txValues[i];
      let dateVal = r[1];
      if (dateVal instanceof Date) {
        dateVal = Utilities.formatDate(dateVal, Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
      }
      transactions.push({
        id: String(r[0]).trim(),
        date: dateVal,
        requester: r[2],
        department: r[3],
        machine_id: r[4],
        total_price: r[5],
        note: r[6],
        status: r[7],
        items: detailsMap[String(r[0]).trim()] || []
      });
    }
  }
  
  saveTransactionsToJson(transactions);
  return transactions;
}

// 9. บันทึกการทำรายการเบิกอะไหล่ (POS Checkout) พร้อมตัดสต็อกตาม FIFO
function checkoutOrder(payload) {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const prodSheet = ss.getSheetByName("Products");
  
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(30000);
  } catch (e) {
    throw new Error("ระบบไม่ว่างชั่วคราว กรุณาลองใหม่อีกครั้ง");
  }
  
  try {
    const prodValues = prodSheet.getDataRange().getValues();
    const cart = payload.cart; 
    let lots = getLotsFromJson();
    
    const prodRowMap = {};
    for (let i = 1; i < prodValues.length; i++) {
      const pid = String(prodValues[i][0]).trim();
      prodRowMap[pid] = {
        rowIndex: i + 1,
        name: prodValues[i][1],
        stock: parseFloat(prodValues[i][10]) || 0,
        cost: parseFloat(prodValues[i][3]) || 0,
        price_a: parseFloat(prodValues[i][4]) || 0,
        price_b: parseFloat(prodValues[i][5]) || 0,
        price_c: parseFloat(prodValues[i][6]) || 0
      };
    }
    
    // ตรวจเช็คสต็อกคงเหลือ
    for (let k = 0; k < cart.length; k++) {
      const item = cart[k];
      const prodId = String(item.id).trim();
      const product = prodRowMap[prodId];
      if (!product) throw new Error("ไม่พบอะไหล่รหัส " + prodId + " ในระบบ");
      if (product.stock < item.qty) {
        throw new Error("สต็อกไม่เพียงพอ: อะไหล่ " + product.name + " (" + prodId + ") มีคงเหลือ " + product.stock + " ชิ้น แต่พยายามเบิก " + item.qty + " ชิ้น");
      }
      
      // ตรวจสอบข้อมูล Lot ว่าพอเพียงหรือไม่ ถ้า Lot ยังน้อยกว่า stock_qty ให้สร้าง Lot สำรองให้อัตโนมัติ
      const prodLots = lots.filter(l => String(l.product_id).trim() === prodId && l.remaining_qty > 0);
      const totalLotQty = prodLots.reduce((sum, l) => sum + l.remaining_qty, 0);
      if (totalLotQty < product.stock) {
        const diff = product.stock - totalLotQty;
        lots.push({
          lot_id: "LOT-SUPP-" + prodId + "-" + Date.now(),
          product_id: prodId,
          cost: product.cost,
          price_a: product.price_a,
          price_b: product.price_b,
          price_c: product.price_c,
          initial_qty: diff,
          remaining_qty: diff,
          created_at: Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss"),
          note: "Lot สำรองคงเหลือ"
        });
      }
    }
    
    // ตัดสต็อกตาม FIFO (First-In, First-Out)
    const checkoutItems = [];
    
    for (let k = 0; k < cart.length; k++) {
      const item = cart[k];
      const prodId = String(item.id).trim();
      let neededQty = item.qty;
      
      // ดึง Lot ของสินค้าตัวนี้ที่ยังเหลืออยู่ เรียงจากสร้างก่อนไปหลัง (FIFO)
      const availableLots = lots.filter(l => String(l.product_id).trim() === prodId && l.remaining_qty > 0)
                                .sort((a, b) => new Date(a.created_at || 0) - new Date(b.created_at || 0));
      
      for (let l = 0; l < availableLots.length && neededQty > 0; l++) {
        const currentLot = availableLots[l];
        const takeQty = Math.min(neededQty, currentLot.remaining_qty);
        
        currentLot.remaining_qty -= takeQty;
        neededQty -= takeQty;
        
        // กำหนดราคาเบิกต่อหน่วยตาม Lot (ถ้ากำหนดระดับราคา A/B/C)
        let lotPrice = item.price;
        if (item.priceLevel === 'A' && currentLot.price_a) lotPrice = currentLot.price_a;
        else if (item.priceLevel === 'B' && currentLot.price_b) lotPrice = currentLot.price_b;
        else if (item.priceLevel === 'C' && currentLot.price_c) lotPrice = currentLot.price_c;
        
        checkoutItems.push({
          detail_id: "",
          product_id: prodId,
          lot_id: currentLot.lot_id,
          qty: takeQty,
          unit_cost: currentLot.cost || 0,
          price: lotPrice,
          subtotal: takeQty * lotPrice
        });
      }
      
      // หักสต็อกในชีต Products
      const product = prodRowMap[prodId];
      const newStock = product.stock - item.qty;
      prodSheet.getRange(product.rowIndex, 11).setValue(newStock);
      product.stock = newStock;
    }
    
    saveLotsToJson(lots);
    
    const now = new Date();
    const dateStr = Utilities.formatDate(now, Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
    const datePrefix = Utilities.formatDate(now, Session.getScriptTimeZone(), "yyyyMMdd");
    
    let transactions = getTransactionsFromJson();
    let counter = 1;
    
    if (transactions.length > 0) {
      const lastTx = transactions[transactions.length - 1];
      if (String(lastTx.id).indexOf("QCM-" + datePrefix) === 0) {
        const parts = String(lastTx.id).split("-");
        const lastNum = parseInt(parts[2], 10);
        if (!isNaN(lastNum)) counter = lastNum + 1;
      }
    }
    const txId = "QCM-" + datePrefix + "-" + String(counter).padStart(4, '0');
    
    let calcTotalPrice = 0;
    checkoutItems.forEach((it, idx) => {
      it.detail_id = txId + "-" + (idx + 1);
      calcTotalPrice += it.subtotal;
    });
    
    const laborCost = parseFloat(payload.labor_cost) || 0;
    const partsTotal = parseFloat(payload.parts_total) || calcTotalPrice;
    const grandTotal = parseFloat(payload.total_price) || (calcTotalPrice + laborCost);

    const newTransaction = {
      id: txId,
      date: dateStr,
      requester: payload.requester || "",
      department: payload.department || "",
      approver: payload.approver || "",
      approver_email: payload.approver_email || "",
      customer_type: payload.customer_type || "",
      price_tier: payload.price_tier || "",
      machine_model: payload.machine_model || "",
      repair_level: payload.repair_level || "",
      labor_cost: laborCost,
      parts_total: partsTotal,
      machine_id: payload.machine_id,
      serial_number: payload.serial_number,
      total_price: grandTotal,
      note: payload.note,
      job_details: payload.job_details || "",
      status: "Success",
      approval_status: payload.approval_status || "Pending",
      items: checkoutItems
    };
    
    transactions.push(newTransaction);
    saveTransactionsToJson(transactions);
    
    return { transaction_id: txId, items: checkoutItems };
    
  } finally {
    lock.releaseLock();
  }
}

// 11. ยกเลิกใบเบิกสินค้า (คืนสต็อกกลับเข้า Products และ Lot เดิม)
function cancelTransaction(payload) {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const prodSheet = ss.getSheetByName("Products");
  
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(30000);
  } catch (e) {
    throw new Error("ระบบไม่ว่างชั่วคราว กรุณาลองใหม่อีกครั้ง");
  }
  
  try {
    const txId = String(payload.transaction_id).trim();
    let transactions = getTransactionsFromJson();
    
    const txIndex = transactions.findIndex(t => t.id === txId);
    if (txIndex === -1) throw new Error("ไม่พบรหัสใบเบิก " + txId);
    
    const targetTx = transactions[txIndex];
    if (targetTx.status === "Cancelled") throw new Error("ใบเบิกนี้ถูกยกเลิกไปแล้ว");
    
    const prodValues = prodSheet.getDataRange().getValues();
    const prodRowMap = {};
    for (let i = 1; i < prodValues.length; i++) {
      prodRowMap[String(prodValues[i][0]).trim()] = {
        rowIndex: i + 1,
        stock: parseFloat(prodValues[i][10]) || 0
      };
    }
    
    let lots = getLotsFromJson();
    
    for (let k = 0; k < targetTx.items.length; k++) {
      const item = targetTx.items[k];
      const prodId = String(item.product_id).trim();
      const product = prodRowMap[prodId];
      if (product) {
        prodSheet.getRange(product.rowIndex, 11).setValue(product.stock + item.qty);
        product.stock += item.qty;
      }
      
      if (item.lot_id) {
        const targetLot = lots.find(l => l.lot_id === item.lot_id);
        if (targetLot) {
          targetLot.remaining_qty += item.qty;
        }
      }
    }
    
    saveLotsToJson(lots);
    
    transactions[txIndex].status = "Cancelled";
    saveTransactionsToJson(transactions);
    
    return { status: "success", message: "ยกเลิกใบเบิกสำเร็จ คืนสต็อกอะไหล่เข้าคลังเรียบร้อยแล้ว" };
  } finally {
    lock.releaseLock();
  }
}

// 11.05 อนุมัติ หรือ ไม่อนุมัติ หรือ แก้ไขรายการอะไหล่ในเอกสารใบขอเบิก
function updateApprovalStatus(payload) {
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(30000);
  } catch (e) {
    throw new Error("ระบบไม่ว่างชั่วคราว กรุณาลองใหม่อีกครั้ง");
  }
  
  try {
    const txId = String(payload.transaction_id).trim();
    const newStatus = payload.approval_status; // 'Approved', 'Rejected', or 'Pending'
    const note = payload.approval_note || "";
    const approverName = payload.approved_by || "";
    const approverEmail = payload.approved_by_email || "";
    
    let transactions = getTransactionsFromJson();
    const txIndex = transactions.findIndex(t => t.id === txId);
    if (txIndex === -1) throw new Error("ไม่พบรหัสใบเบิก " + txId);
    
    const targetTx = transactions[txIndex];
    if (targetTx.approval_status === "Approved" || targetTx.approval_status === "Rejected") {
      throw new Error("เอกสารนี้ได้รับการพิจารณาไปแล้ว (" + targetTx.approval_status + ")");
    }
    
    const now = new Date();
    const dateStr = Utilities.formatDate(now, Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
    
    const hasUpdatedItems = Array.isArray(payload.updated_items) && payload.updated_items.length > 0;

    if (newStatus === "Rejected") {
      targetTx.approval_status = "Rejected";
      targetTx.approval_date = dateStr;
      targetTx.approval_by = approverName;
      targetTx.approval_by_email = approverEmail;
      targetTx.approval_note = note;
      targetTx.status = "Cancelled";
      
      const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
      const prodSheet = ss.getSheetByName("Products");
      const prodValues = prodSheet.getDataRange().getValues();
      const prodRowMap = {};
      for (let i = 1; i < prodValues.length; i++) {
        prodRowMap[String(prodValues[i][0]).trim()] = {
          rowIndex: i + 1,
          stock: parseFloat(prodValues[i][10]) || 0
        };
      }
      
      let lots = getLotsFromJson();
      
      if (Array.isArray(targetTx.items)) {
        for (let k = 0; k < targetTx.items.length; k++) {
          const item = targetTx.items[k];
          const prodId = String(item.product_id).trim();
          const product = prodRowMap[prodId];
          if (product) {
            prodSheet.getRange(product.rowIndex, 11).setValue(product.stock + item.qty);
            product.stock += item.qty;
          }
          
          if (item.lot_id) {
            const targetLot = lots.find(l => l.lot_id === item.lot_id);
            if (targetLot) {
              targetLot.remaining_qty += item.qty;
            }
          }
        }
      }
      
      saveLotsToJson(lots);
    } else {
      // 'Approved' or 'Pending'
      if (hasUpdatedItems) {
        const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
        const prodSheet = ss.getSheetByName("Products");
        const prodValues = prodSheet.getDataRange().getValues();
        const prodRowMap = {};
        for (let i = 1; i < prodValues.length; i++) {
          const pid = String(prodValues[i][0]).trim();
          prodRowMap[pid] = {
            rowIndex: i + 1,
            name: prodValues[i][1],
            stock: parseFloat(prodValues[i][10]) || 0,
            cost: parseFloat(prodValues[i][3]) || 0,
            price_a: parseFloat(prodValues[i][4]) || 0,
            price_b: parseFloat(prodValues[i][5]) || 0,
            price_c: parseFloat(prodValues[i][6]) || 0
          };
        }
        
        let lots = getLotsFromJson();
        
        // 1. คืนสต็อกและล็อตเดิมก่อนคำนวณใหม่
        if (Array.isArray(targetTx.items)) {
          for (let k = 0; k < targetTx.items.length; k++) {
            const oldItem = targetTx.items[k];
            const oldPid = String(oldItem.product_id).trim();
            const oldProd = prodRowMap[oldPid];
            if (oldProd) {
              oldProd.stock += (Number(oldItem.qty) || 0);
            }
            if (oldItem.lot_id) {
              const targetLot = lots.find(l => l.lot_id === oldItem.lot_id);
              if (targetLot) {
                targetLot.remaining_qty += (Number(oldItem.qty) || 0);
              }
            }
          }
        }
        
        // 2. ตรวจสอบสต็อกสำหรับรายการใหม่ทั้งหมด
        const productNeededTotals = {};
        for (let k = 0; k < payload.updated_items.length; k++) {
          const item = payload.updated_items[k];
          const prodId = String(item.product_id || item.id).trim();
          const q = Number(item.qty) || 0;
          if (q <= 0) throw new Error("จำนวนอะไหล่ต้องมากกว่า 0");
          productNeededTotals[prodId] = (productNeededTotals[prodId] || 0) + q;
        }

        for (const prodId in productNeededTotals) {
          const product = prodRowMap[prodId];
          if (!product) throw new Error("ไม่พบรหัสสินค้า " + prodId + " ในระบบ");
          const totalReq = productNeededTotals[prodId];
          if (product.stock < totalReq) {
            throw new Error("สต็อกไม่เพียงพอ: อะไหล่ " + product.name + " (" + prodId + ") มีคงเหลือ " + product.stock + " ชิ้น แต่ต้องการเบิก " + totalReq + " ชิ้น");
          }
          
          // ตรวจสอบ Lot สำรอง
          const prodLots = lots.filter(l => String(l.product_id).trim() === prodId && l.remaining_qty > 0);
          const totalLotQty = prodLots.reduce((sum, l) => sum + l.remaining_qty, 0);
          if (totalLotQty < product.stock) {
            const diff = product.stock - totalLotQty;
            lots.push({
              lot_id: "LOT-SUPP-" + prodId + "-" + Date.now() + "-" + Math.floor(Math.random() * 1000),
              product_id: prodId,
              cost: product.cost,
              price_a: product.price_a,
              price_b: product.price_b,
              price_c: product.price_c,
              initial_qty: diff,
              remaining_qty: diff,
              created_at: Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss"),
              note: "Lot สำรองคงเหลือ (ปรับปรุงรายการอนุมัติ)"
            });
          }
        }
        
        // 3. ตัดสต็อกตาม FIFO สำหรับรายการใหม่
        const checkoutItems = [];
        for (let k = 0; k < payload.updated_items.length; k++) {
          const item = payload.updated_items[k];
          const prodId = String(item.product_id || item.id).trim();
          const product = prodRowMap[prodId];
          let neededQty = Number(item.qty) || 0;
          
          const availableLots = lots.filter(l => String(l.product_id).trim() === prodId && l.remaining_qty > 0)
                                    .sort((a, b) => new Date(a.created_at || 0) - new Date(b.created_at || 0));
          
          for (let l = 0; l < availableLots.length && neededQty > 0; l++) {
            const currentLot = availableLots[l];
            const takeQty = Math.min(neededQty, currentLot.remaining_qty);
            currentLot.remaining_qty -= takeQty;
            neededQty -= takeQty;
            
            const lotPrice = Number(item.price) || 0;
            checkoutItems.push({
              detail_id: "",
              product_id: prodId,
              lot_id: currentLot.lot_id,
              qty: takeQty,
              unit_cost: currentLot.cost || 0,
              price: lotPrice,
              subtotal: takeQty * lotPrice
            });
          }
          
          product.stock -= (Number(item.qty) || 0);
        }
        
        // บันทึกสต็อกสินค้ากลับลง Products sheet
        for (const pid in prodRowMap) {
          const p = prodRowMap[pid];
          prodSheet.getRange(p.rowIndex, 11).setValue(p.stock);
        }
        saveLotsToJson(lots);
        
        // บันทึกรายการใหม่และคำนวณยอดรวมใน transaction
        targetTx.items = checkoutItems;
        const newPartsTotal = checkoutItems.reduce((sum, it) => sum + (it.qty * it.price), 0);
        targetTx.parts_total = newPartsTotal;
        targetTx.total_price = newPartsTotal + (Number(targetTx.labor_cost) || 0);
      }
      
      if (newStatus === "Approved") {
        targetTx.approval_status = "Approved";
        targetTx.approval_date = dateStr;
        targetTx.approval_by = approverName;
        targetTx.approval_by_email = approverEmail;
        targetTx.approval_note = note;
      } else if (newStatus === "Pending") {
        if (note) targetTx.approval_note = note;
      }
    }
    
    saveTransactionsToJson(transactions);
    return {
      status: "success",
      transaction_id: txId,
      approval_status: targetTx.approval_status,
      items: targetTx.items,
      parts_total: targetTx.parts_total,
      total_price: targetTx.total_price,
      message: newStatus === "Approved" ? "อนุมัติเอกสารสำเร็จ" : (newStatus === "Rejected" ? "ปฏิเสธเอกสารและคืนสต็อกสำเร็จ" : "บันทึกการแก้ไขรายการอะไหล่สำเร็จ")
    };
  } finally {
    lock.releaseLock();
  }
}

function hashPassword(password) {
  const digest = Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, password, Utilities.Charset.UTF_8);
  let hexString = "";
  for (let i = 0; i < digest.length; i++) {
    let byteVal = digest[i];
    if (byteVal < 0) byteVal += 256;
    let byteString = byteVal.toString(16);
    if (byteString.length == 1) byteString = "0" + byteString;
    hexString += byteString;
  }
  return hexString;
}

    const emailConflict = users.some(u => String(u.email).toLowerCase() === email);
    if (emailConflict) {
       throw new Error("อีเมลนี้ถูกใช้สมัครสมาชิกแล้ว");
    }
    if (currentEmail === 'nakyeet@gmail.com') {
       throw new Error("ไม่สามารถเปลี่ยนอีเมลผู้ใช้ตั้งต้นระบบได้");
    }
  }
  
  if (phone !== user.phone) {
    const phoneConflict = users.some(u => String(u.phone).trim() === phone);
    if (phoneConflict) {
       throw new Error("เบอร์โทรศัพท์นี้ถูกใช้สมัครสมาชิกแล้ว");
    }
  }
  
  user.fullName = fullName;
  user.department = department;
  user.phone = phone;
  user.email = email;
  if (password) {
    user.passwordHash = hashPassword(password);
  }
  
  saveUsersJSON(users);
  return {
    fullName: user.fullName,
    department: user.department,
    phone: user.phone,
    email: user.email,
    role: user.role,
    priceLevel: user.priceLevel || "A",
    userType: user.userType || "insource",
    canApprove: !!user.canApprove
  };
}

// 12. บันทึกการเพิ่มสต็อกสินค้า (Restock) พร้อมอัปเดตสต็อกในชีต Products และสร้าง Lot ใหม่ลง JSON
function restockProduct(payload) {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const prodSheet = ss.getSheetByName("Products");
  
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(30000);
  } catch (e) {
    throw new Error("ระบบไม่ว่างชั่วคราว กรุณาลองใหม่อีกครั้ง");
  }
  
  try {
    const prodValues = prodSheet.getDataRange().getValues();
    const productId = String(payload.id).trim();
    const qtyToAdd = parseFloat(payload.qty) || 0;
    
    if (qtyToAdd === 0) throw new Error("จำนวนที่ปรับเปลี่ยนต้องไม่เป็น 0");
    
    let rowIndex = -1;
    let currentStock = 0;
    let currentCost = 0;
    let currentPriceA = 0, currentPriceB = 0, currentPriceC = 0;
    
    for (let i = 1; i < prodValues.length; i++) {
      if (String(prodValues[i][0]).trim() === productId) {
        rowIndex = i + 1;
        currentCost = parseFloat(prodValues[i][3]) || 0;
        currentPriceA = parseFloat(prodValues[i][4]) || 0;
        currentPriceB = parseFloat(prodValues[i][5]) || 0;
        currentPriceC = parseFloat(prodValues[i][6]) || 0;
        currentStock = parseFloat(prodValues[i][10]) || 0;
        break;
      }
    }
    
    if (rowIndex === -1) throw new Error("ไม่พบอะไหล่รหัส " + productId);
    
    const newStock = currentStock + qtyToAdd;
    if (newStock < 0) throw new Error("ยอดสต็อกหลังปรับปรุงต้องไม่ต่ำกว่า 0 (สต็อกปัจจุบัน: " + currentStock + ", ปรับปรุง: " + qtyToAdd + ")");
    
    // รับค่าต้นทุนและราคาขายใหม่ของ Lot (หากระบุ)
    const lotCost = (payload.cost !== undefined && payload.cost !== "") ? parseFloat(payload.cost) : currentCost;
    const autoPrices = calculatePrices(lotCost);
    const lotPriceA = (payload.price_a !== undefined && payload.price_a !== "") ? parseFloat(payload.price_a) : (currentPriceA || autoPrices.price_a);
    const lotPriceB = (payload.price_b !== undefined && payload.price_b !== "") ? parseFloat(payload.price_b) : (currentPriceB || autoPrices.price_b);
    const lotPriceC = (payload.price_c !== undefined && payload.price_c !== "") ? parseFloat(payload.price_c) : (currentPriceC || autoPrices.price_c);
    
    // อัปเดตสต็อกคงเหลือ และราคาอ้างอิงล่าสุดใน Products Sheet
    prodSheet.getRange(rowIndex, 11).setValue(newStock);
    if (payload.cost !== undefined && payload.cost !== "") {
      prodSheet.getRange(rowIndex, 4, 1, 4).setValues([[lotCost, lotPriceA, lotPriceB, lotPriceC]]);
    }
    
    // สร้าง Lot ใหม่ใน lots.json
    let lots = getLotsFromJson();
    const now = new Date();
    const dateStr = Utilities.formatDate(now, Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
    const datePrefix = Utilities.formatDate(now, Session.getScriptTimeZone(), "yyyyMMdd");
    
    const lotId = "LOT-" + datePrefix + "-" + String(Date.now()).slice(-6);
    lots.push({
      lot_id: lotId,
      product_id: productId,
      cost: lotCost,
      price_a: lotPriceA,
      price_b: lotPriceB,
      price_c: lotPriceC,
      initial_qty: qtyToAdd,
      remaining_qty: qtyToAdd,
      created_at: dateStr,
      note: payload.note || "เติมสต็อกอะไหล่"
    });
    saveLotsToJson(lots);
    
    // บันทึกประวัติการเติมสต็อกลงใน transactions.json
    let transactions = getTransactionsFromJson();
    let counter = 1;
    
    if (transactions.length > 0) {
      for (let i = transactions.length - 1; i >= 0; i--) {
        const lastTx = transactions[i];
        if (String(lastTx.id).indexOf("QCM-RE-" + datePrefix) === 0) {
          const parts = String(lastTx.id).split("-");
          const lastNum = parseInt(parts[3], 10);
          if (!isNaN(lastNum)) {
            counter = lastNum + 1;
            break;
          }
        }
      }
    }
    const txId = "QCM-RE-" + datePrefix + "-" + String(counter).padStart(4, '0');
    
    const newRestockTransaction = {
      id: txId,
      date: dateStr,
      requester: payload.requester || "ระบบเติมสต็อก",
      department: payload.department || "สโตร์ (Restock)",
      machine_id: "",
      serial_number: "",
      total_price: qtyToAdd * lotCost,
      note: payload.note || ("เติมสต็อก (Lot: " + lotId + ")"),
      status: "Restock",
      items: [{
        detail_id: txId + "-1",
        product_id: productId,
        lot_id: lotId,
        qty: qtyToAdd,
        unit_cost: lotCost,
        price: lotPriceA,
        subtotal: qtyToAdd * lotCost
      }]
    };
    
    transactions.push(newRestockTransaction);
    saveTransactionsToJson(transactions);
    
    return { new_stock: newStock, transaction_id: txId, lot_id: lotId };
    
  } finally {
    lock.releaseLock();
  }
}

// ฟังก์ชันอัปโหลดไฟล์คู่มือ (PDF หรือ รูปภาพ) ลงใน Google Drive
function uploadManualFileToDrive(base64Data, fileName, mimeType) {
  try {
    if (!base64Data) return "";
    // ถ้าเป็น URL อยู่แล้ว (เช่น ลิงก์เดิม) ไม่ต้องอัพโหลดซ้ำ
    if (base64Data.indexOf('http://') === 0 || base64Data.indexOf('https://') === 0) {
      return base64Data;
    }
    const parts = base64Data.split(',');
    let type = mimeType || "application/pdf";
    if (parts.length > 1 && parts[0].indexOf(';base64') !== -1) {
      const match = parts[0].match(/data:(.*?);base64/);
      if (match && match[1]) type = match[1];
    }
    const base64 = parts[1] || base64Data;
    const decoded = Utilities.base64Decode(base64);
    
    // ตั้งนามสกุลไฟล์ตามประเภท
    let ext = ".pdf";
    if (type.indexOf('image/png') !== -1) ext = ".png";
    else if (type.indexOf('image/jpeg') !== -1 || type.indexOf('image/jpg') !== -1) ext = ".jpg";
    else if (type.indexOf('image/webp') !== -1) ext = ".webp";
    
    const finalFileName = (fileName || ("manual_" + Date.now())) + ext;
    const blob = Utilities.newBlob(decoded, type, finalFileName);
    
    const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID);
    const file = folder.createFile(blob);
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    // ลิงก์ดาวน์โหลดตรงจาก Google Drive
    return 'https://drive.google.com/uc?export=download&id=' + file.getId();
  } catch (e) {
    Logger.log("อัปโหลดไฟล์คู่มือลง Google Drive ล้มเหลว: " + e.toString());
    return base64Data;
  }
}

function addManual(payload) {
  initDatabase();
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const sheet = ss.getSheetByName("Manuals");
  const nowStr = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd");
  const id = payload.id || ("MAN-" + String(Date.now()).slice(-6));
  
  let fileUrl = payload.file_url || "";
  if (fileUrl && fileUrl.indexOf("data:") === 0) {
    const uploadedUrl = uploadManualFileToDrive(fileUrl, (payload.title || "manual") + "_" + id, payload.file_type);
    if (uploadedUrl) fileUrl = uploadedUrl;
  }
  
  sheet.appendRow([
    id,
    payload.title || "",
    payload.description || "",
    fileUrl,
    payload.file_type || "",
    nowStr
  ]);
  
  return { id: id, file_url: fileUrl };
}

function editManual(payload) {
  initDatabase();
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const sheet = ss.getSheetByName("Manuals");
  const data = sheet.getDataRange().getValues();
  const targetId = String(payload.id).trim();
  
  let fileUrl = payload.file_url || "";
  if (fileUrl && fileUrl.indexOf("data:") === 0) {
    const uploadedUrl = uploadManualFileToDrive(fileUrl, (payload.title || "manual") + "_" + targetId, payload.file_type);
    if (uploadedUrl) fileUrl = uploadedUrl;
  }
  
  for (let i = 1; i < data.length; i++) {
    if (String(data[i][0]).trim() === targetId) {
      sheet.getRange(i + 1, 2).setValue(payload.title || "");
      sheet.getRange(i + 1, 3).setValue(payload.description || "");
      if (fileUrl) sheet.getRange(i + 1, 4).setValue(fileUrl);
      if (payload.file_type) sheet.getRange(i + 1, 5).setValue(payload.file_type);
      break;
    }
  }
  return { status: "success", file_url: fileUrl };
}

function getFirebaseWriteRequest(path, data) {
  if (!FIREBASE_URL || FIREBASE_URL === "") {
    throw new Error("FIREBASE_URL is not configured.");
  }
  let baseUrl = FIREBASE_URL;
  if (baseUrl.charAt(baseUrl.length - 1) !== '/') {
    baseUrl += '/';
  }
  const url = baseUrl + path + ".json" + (FIREBASE_SECRET ? "?auth=" + FIREBASE_SECRET : "");
  return {
    url: url,
    method: "put",
    contentType: "application/json",
    payload: JSON.stringify(data),
    muteHttpExceptions: true
  };
}

function runUploadSheetsToFirebase(targets) {
  const ui = SpreadsheetApp.getUi();
  const isSelected = (name) => targets.indexOf(name) !== -1;
  
  try {
    initDatabase();
    const ss = SpreadsheetApp.getActiveSpreadsheet() || SpreadsheetApp.openById(SPREADSHEET_ID);
    
    let products = null;
    let machines = null;
    let settings = null;
    let manuals = null;
    let transactions = null;
    let mappings = null;
    let lots = null;
    let users = null;
    
    const firebaseRequests = [];
    
    // 1. อ่าน Products
    if (isSelected('products')) {
      const prodSheet = ss.getSheetByName("Products");
      const prodData = prodSheet.getDataRange().getValues();
      products = [];
      if (prodData.length > 1) {
        for (let i = 1; i < prodData.length; i++) {
          let r = prodData[i];
          products.push({
            id: r[0], name: r[1], unit: r[2], cost: parseFloat(r[3]) || 0,
            price_a: parseFloat(r[4]) || 0, price_b: parseFloat(r[5]) || 0, price_c: parseFloat(r[6]) || 0,
            category: r[7], note: r[8], image_url: r[9],
            stock_qty: (r[10] !== undefined && r[10] !== "") ? parseFloat(r[10]) : 0,
            group: r[11] || "", supplier: r[12] || "", storage: r[13] || ""
          });
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("appData/products", products));
    }
    
    // 2. อ่าน Machines
    if (isSelected('machines')) {
      const machSheet = ss.getSheetByName("Machines");
      const machData = machSheet.getDataRange().getValues();
      machines = [];
      if (machData.length > 1) {
        for (let i = 1; i < machData.length; i++) {
          let r = machData[i];
          machines.push({ 
            id: r[0], name: r[1], image_url: r[2] || '', cost: parseFloat(r[3]) || 0,
            price_a: parseFloat(r[4]) || 0, price_b: parseFloat(r[5]) || 0, price_c: parseFloat(r[6]) || 0,
            note: r[7] || '', group: r[8] || '', supplier: r[9] || '', storage: r[10] || ''
          });
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("appData/machines", machines));
    }
    
    // 3. อ่าน Settings
    if (isSelected('settings')) {
      const settingsSheet = ss.getSheetByName("Settings");
      settings = { isShowPriceBForGuest: false, isShowPriceCForGuest: false };
      if (settingsSheet) {
        const settingsData = settingsSheet.getDataRange().getValues();
        if (settingsData.length > 1) {
          for (let i = 1; i < settingsData.length; i++) {
            let key = settingsData[i][0];
            let val = settingsData[i][1];
            if (key === "isShowPriceBForGuest") settings.isShowPriceBForGuest = (String(val).toLowerCase() === "true");
            if (key === "isShowPriceCForGuest") settings.isShowPriceCForGuest = (String(val).toLowerCase() === "true");
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("appData/settings", settings));
    }
    
    // 4. อ่าน Manuals
    if (isSelected('manuals')) {
      const manSheet = ss.getSheetByName("Manuals");
      manuals = [];
      if (manSheet) {
        const manData = manSheet.getDataRange().getValues();
        if (manData.length > 1) {
          for (let i = 1; i < manData.length; i++) {
            manuals.push({
              id: manData[i][0], title: manData[i][1], description: manData[i][2] || '',
              file_url: manData[i][3] || '', file_type: manData[i][4] || '', uploaded_at: manData[i][5] || ''
            });
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("appData/manuals", manuals));
    }
    
    // 5. อ่าน Transactions จาก Sheet
    if (isSelected('transactions')) {
      const txSheet = ss.getSheetByName("Transactions");
      if (txSheet) {
        const txData = txSheet.getDataRange().getValues();
        transactions = [];
        if (txData.length > 1) {
          for (let i = 1; i < txData.length; i++) {
            let items = [];
            try {
              items = JSON.parse(txData[i][22] || txData[i][9] || "[]");
            } catch(e) {}
            transactions.push({
              id: txData[i][0], requester: txData[i][1], department: txData[i][2],
              approver: txData[i][3] || "", approver_email: txData[i][4] || "",
              customer_type: txData[i][5] || "", price_tier: txData[i][6] || "",
              machine_model: txData[i][7] || "", repair_level: txData[i][8] || "",
              labor_cost: parseFloat(txData[i][9]) || 0, parts_total: parseFloat(txData[i][10]) || 0,
              machine_id: txData[i][11] || "", serial_number: txData[i][12] || "",
              total_price: parseFloat(txData[i][13]) || 0, note: txData[i][14] || "",
              job_details: txData[i][15] || "", created_at: String(txData[i][16] || ""),
              status: txData[i][17] || "Success", approval_status: txData[i][18] || "Pending",
              approval_date: txData[i][19] || "", approval_by: txData[i][20] || "",
              approval_note: txData[i][21] || "", items: items
            });
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("transactions", transactions));
    }

    // 6. อ่าน Mappings จาก Sheet
    if (isSelected('mappings')) {
      const mapSheet = ss.getSheetByName("Mappings");
      if (mapSheet) {
        const mapData = mapSheet.getDataRange().getValues();
        mappings = [];
        if (mapData.length > 1) {
          for (let i = 1; i < mapData.length; i++) {
            mappings.push({
              product_id: String(mapData[i][0]).trim(),
              machine_id: String(mapData[i][1]).trim()
            });
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("mappings", mappings));
    }

    // 7. อ่าน Lots จาก Sheet
    if (isSelected('lots')) {
      const lotsSheet = ss.getSheetByName("Lots");
      if (lotsSheet) {
        const lotsData = lotsSheet.getDataRange().getValues();
        lots = [];
        if (lotsData.length > 1) {
          for (let i = 1; i < lotsData.length; i++) {
            lots.push({
              lot_id: String(lotsData[i][0]).trim(),
              product_id: String(lotsData[i][1]).trim(),
              cost: parseFloat(lotsData[i][2]) || 0,
              price_a: parseFloat(lotsData[i][3]) || 0,
              price_b: parseFloat(lotsData[i][4]) || 0,
              price_c: parseFloat(lotsData[i][5]) || 0,
              initial_qty: parseFloat(lotsData[i][6]) || 0,
              remaining_qty: parseFloat(lotsData[i][7]) || 0,
              created_at: String(lotsData[i][8]),
              note: String(lotsData[i][9])
            });
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("lots", lots));
    }

    // 8. อ่าน Users จาก Sheet
    if (isSelected('users')) {
      const usersSheet = ss.getSheetByName("Users");
      if (usersSheet) {
        const usersData = usersSheet.getDataRange().getValues();
        users = [];
        if (usersData.length > 1) {
          for (let i = 1; i < usersData.length; i++) {
            users.push({
              fullName: String(usersData[i][0]).trim(),
              department: String(usersData[i][1]).trim(),
              phone: String(usersData[i][2]).trim(),
              email: String(usersData[i][3]).trim().toLowerCase(),
              passwordHash: String(usersData[i][4]).trim(),
              role: String(usersData[i][5]).trim() || "user",
              priceLevel: String(usersData[i][6]).trim() || "A",
              userType: String(usersData[i][7]).trim() || "insource",
              canApprove: usersData[i][8] !== undefined ? (String(usersData[i][8]).toLowerCase() === "true" || usersData[i][8] === true) : false
            });
          }
        }
      }
      firebaseRequests.push(getFirebaseWriteRequest("users", users));
    }

    // ยิงคำขอเขียนลง Firebase พร้อมกันทั้งหมดในรอบเดียว
    if (firebaseRequests.length > 0) {
      const responses = UrlFetchApp.fetchAll(firebaseRequests);
      for (let i = 0; i < responses.length; i++) {
        if (responses[i].getResponseCode() !== 200) {
          throw new Error("Failed to write to Firebase: " + responses[i].getContentText());
        }
      }
    }
    
    ui.alert('✅ สำเร็จ', 'อัปโหลดข้อมูลจาก Google Sheet ขึ้น Firebase เรียบร้อยแล้ว', ui.ButtonSet.OK);
  } catch (e) {
    ui.alert('❌ ผิดพลาด', 'เกิดข้อผิดพลาดในการอัปโหลด: ' + e.toString(), ui.ButtonSet.OK);
  }
}

function runUploadJsonToFirebase(targets) {
  const ui = SpreadsheetApp.getUi();
  const isSelected = (name) => targets.indexOf(name) !== -1;
  
  try {
    initDatabase();
    const folder = DriveApp.getFolderById(JSON_FOLDER_ID);
    const firebaseRequests = [];
    
    // 1. อัปโหลด app_data.json
    const appDataFiles = folder.getFilesByName("app_data.json");
    if (appDataFiles.hasNext()) {
      const appData = JSON.parse(appDataFiles.next().getBlob().getDataAsString());
      if (appData) {
        if (isSelected('products')) firebaseRequests.push(getFirebaseWriteRequest("appData/products", appData.products || []));
        if (isSelected('machines')) firebaseRequests.push(getFirebaseWriteRequest("appData/machines", appData.machines || []));
        if (isSelected('mappings')) firebaseRequests.push(getFirebaseWriteRequest("mappings", appData.mappings || []));
        if (isSelected('settings')) firebaseRequests.push(getFirebaseWriteRequest("appData/settings", appData.settings || {}));
        if (isSelected('manuals')) firebaseRequests.push(getFirebaseWriteRequest("appData/manuals", appData.manuals || []));
        if (isSelected('lots')) firebaseRequests.push(getFirebaseWriteRequest("lots", appData.lots || []));
      }
    }
    
    // 2. อัปโหลด transactions.json
    if (isSelected('transactions')) {
      const txFiles = folder.getFilesByName("transactions.json");
      if (txFiles.hasNext()) {
        const transactions = JSON.parse(txFiles.next().getBlob().getDataAsString());
        if (transactions) firebaseRequests.push(getFirebaseWriteRequest("transactions", transactions));
      }
    }
    
    // 3. อัปโหลด users.json
    if (isSelected('users')) {
      const userFiles = folder.getFilesByName("users.json");
      if (userFiles.hasNext()) {
        const users = JSON.parse(userFiles.next().getBlob().getDataAsString());
        if (users) firebaseRequests.push(getFirebaseWriteRequest("users", users));
      }
    }
    
    if (firebaseRequests.length > 0) {
      const responses = UrlFetchApp.fetchAll(firebaseRequests);
      for (let i = 0; i < responses.length; i++) {
        if (responses[i].getResponseCode() !== 200) {
          throw new Error("Failed to write to Firebase: " + responses[i].getContentText());
        }
      }
    }
    
    ui.alert('✅ สำเร็จ', 'อัปโหลดข้อมูลจาก JSON ใน Google Drive ขึ้น Firebase เรียบร้อยแล้ว', ui.ButtonSet.OK);
  } catch (e) {
    ui.alert('❌ ผิดพลาด', 'เกิดข้อผิดพลาดในการอัปโหลด: ' + e.toString(), ui.ButtonSet.OK);
  }
}

function backupFirebaseToDrive(payload) {
  const targets = (payload && payload.targets) ? payload.targets : ['products', 'machines', 'mappings', 'settings', 'manuals', 'lots', 'transactions', 'users'];
  const isSelected = (name) => targets.indexOf(name) !== -1;
  const folder = DriveApp.getFolderById(JSON_FOLDER_ID);
  
  let existingAppData = {};
  const appDataFiles = folder.getFilesByName("app_data.json");
  let appDataFile = null;
  if (appDataFiles.hasNext()) {
    appDataFile = appDataFiles.next();
    try {
      existingAppData = JSON.parse(appDataFile.getBlob().getDataAsString()) || {};
    } catch(e) {
      existingAppData = {};
    }
  }
  
  if (isSelected('products')) {
    existingAppData.products = getFirebaseData("appData/products") || [];
  }
  if (isSelected('machines')) {
    existingAppData.machines = getFirebaseData("appData/machines") || [];
  }
  if (isSelected('mappings')) {
    existingAppData.mappings = getFirebaseData("mappings") || [];
  }
  if (isSelected('settings')) {
    existingAppData.settings = getFirebaseData("appData/settings") || { isShowPriceBForGuest: false, isShowPriceCForGuest: false };
  }
  if (isSelected('manuals')) {
    existingAppData.manuals = getFirebaseData("appData/manuals") || [];
  }
  if (isSelected('lots')) {
    existingAppData.lots = getFirebaseData("lots") || [];
  }
  
  const appDataKeys = ['products', 'machines', 'mappings', 'settings', 'manuals', 'lots'];
  const hasAppDataTarget = targets.some(t => appDataKeys.includes(t));
  if (hasAppDataTarget) {
    appDataKeys.forEach(k => {
      if (existingAppData[k] === undefined) {
        if (k === 'settings') {
          existingAppData[k] = getFirebaseData("appData/" + k) || { isShowPriceBForGuest: false, isShowPriceCForGuest: false };
        } else {
          existingAppData[k] = getFirebaseData(k === 'mappings' || k === 'lots' ? k : "appData/" + k) || [];
        }
      }
    });
    
    const appDataContent = JSON.stringify(existingAppData);
    if (appDataFile) {
      appDataFile.setContent(appDataContent);
    } else {
      folder.createFile("app_data.json", appDataContent, MimeType.PLAIN_TEXT);
    }
  }
  
  if (isSelected('lots')) {
    const lots = getFirebaseData("lots") || [];
    const lotsFiles = folder.getFilesByName("lots.json");
    const lotsContent = JSON.stringify(lots);
    if (lotsFiles.hasNext()) {
      lotsFiles.next().setContent(lotsContent);
    } else {
      folder.createFile("lots.json", lotsContent, MimeType.PLAIN_TEXT);
    }
  }
  
  if (isSelected('mappings')) {
    const mappings = getFirebaseData("mappings") || [];
    const mapFiles = folder.getFilesByName("mappings.json");
    const mapContent = JSON.stringify(mappings);
    if (mapFiles.hasNext()) {
      mapFiles.next().setContent(mapContent);
    } else {
      folder.createFile("mappings.json", mapContent, MimeType.PLAIN_TEXT);
    }
  }

  if (isSelected('transactions')) {
    const transactions = getFirebaseData("transactions") || [];
    const txFiles = folder.getFilesByName("transactions.json");
    const txContent = JSON.stringify(transactions);
    if (txFiles.hasNext()) {
      txFiles.next().setContent(txContent);
    } else {
      folder.createFile("transactions.json", txContent, MimeType.PLAIN_TEXT);
    }
  }
  
  if (isSelected('users')) {
    const users = getFirebaseData("users") || [];
    const userFiles = folder.getFilesByName("users.json");
    const userContent = JSON.stringify(users);
    if (userFiles.hasNext()) {
      userFiles.next().setContent(userContent);
    } else {
      folder.createFile("users.json", userContent, MimeType.PLAIN_TEXT);
    }
  }
}

function backupFirebaseToSheets(payload) {
  const targets = (payload && payload.targets) ? payload.targets : ['products', 'machines', 'mappings', 'settings', 'manuals', 'lots', 'transactions', 'users'];
  const isSelected = (name) => targets.indexOf(name) !== -1;
  const ss = SpreadsheetApp.getActiveSpreadsheet() || SpreadsheetApp.openById(SPREADSHEET_ID);
  
  // 1. Products Sheet
  if (isSelected('products')) {
    const products = getFirebaseData("appData/products") || [];
    const prodSheet = ss.getSheetByName("Products");
    if (prodSheet) {
      prodSheet.clearContents();
      const rows = [["Product_ID", "Product_Name", "Unit", "Cost", "Price_A", "Price_B", "Price_C", "Category", "Note", "Image_URL", "Stock_Qty", "Product_Group", "Supplier", "Storage_Area"]];
      products.forEach(p => {
        rows.push([
          p.id, p.name, p.unit, p.cost, p.price_a, p.price_b, p.price_c,
          p.category, p.note, p.image_url, p.stock_qty, p.group || "", p.supplier || "", p.storage || ""
        ]);
      });
      prodSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }
  
  // 2. Machines Sheet
  if (isSelected('machines')) {
    const machines = getFirebaseData("appData/machines") || [];
    const machSheet = ss.getSheetByName("Machines");
    if (machSheet) {
      machSheet.clearContents();
      const rows = [["Machine_ID", "Machine_Name", "Image_URL", "Cost", "Price_A", "Price_B", "Price_C", "Note", "Machine_Group", "Supplier", "Storage_Area"]];
      machines.forEach(m => {
        rows.push([
          m.id, m.name, m.image_url || "", m.cost || 0, m.price_a || 0, m.price_b || 0, m.price_c || 0, m.note || "",
          m.group || "", m.supplier || "", m.storage || ""
        ]);
      });
      machSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }
  
  // 3. Settings Sheet
  if (isSelected('settings')) {
    const settings = getFirebaseData("appData/settings") || {};
    const settingsSheet = ss.getSheetByName("Settings");
    if (settingsSheet) {
      settingsSheet.clearContents();
      const rows = [
        ["Setting_Key", "Setting_Value"],
        ["isShowPriceBForGuest", settings.isShowPriceBForGuest ? "true" : "false"],
        ["isShowPriceCForGuest", settings.isShowPriceCForGuest ? "true" : "false"]
      ];
      settingsSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }
  
  // 4. Manuals Sheet
  if (isSelected('manuals')) {
    const manuals = getFirebaseData("appData/manuals") || [];
    const manSheet = ss.getSheetByName("Manuals");
    if (manSheet) {
      manSheet.clearContents();
      const rows = [["Manual_ID", "Title", "Description", "File_URL", "File_Type", "Uploaded_At"]];
      manuals.forEach(m => {
        rows.push([
          m.id, m.title, m.description || "", m.file_url || "", m.file_type || "", m.uploaded_at || ""
        ]);
      });
      manSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }

  // 5. Transactions Sheet
  if (isSelected('transactions')) {
    const transactions = getFirebaseData("transactions") || [];
    const txSheet = ss.getSheetByName("Transactions");
    if (txSheet) {
      txSheet.clearContents();
      const rows = [["Transaction_ID", "Requester", "Department", "Approver", "Approver_Email", "Customer_Type", "Price_Tier", "Machine_Model", "Repair_Level", "Labor_Cost", "Parts_Total", "Machine_ID", "Serial_Number", "Total_Price", "Note", "Job_Details", "Created_At", "Status", "Approval_Status", "Approval_Date", "Approval_By", "Approval_Note", "Items_JSON"]];
      transactions.forEach(t => {
        rows.push([
          t.id, t.requester, t.department, t.approver || "", t.approver_email || "",
          t.customer_type || "", t.price_tier || "", t.machine_model || "", t.repair_level || "",
          t.labor_cost || 0, t.parts_total || 0, t.machine_id || "", t.serial_number || "",
          t.total_price || 0, t.note || "", t.job_details || "", t.created_at || t.date || "",
          t.status || "Success", t.approval_status || "Pending", t.approval_date || "",
          t.approval_by || "", t.approval_note || "", JSON.stringify(t.items || [])
        ]);
      });
      txSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }

  // 6. Mappings Sheet
  if (isSelected('mappings')) {
    const mappings = getFirebaseData("mappings") || [];
    const mapSheet = ss.getSheetByName("Mappings");
    if (mapSheet) {
      mapSheet.clearContents();
      const rows = [["Product_ID", "Machine_ID"]];
      mappings.forEach(m => {
        rows.push([m.product_id, m.machine_id]);
      });
      mapSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }

  // 7. Lots Sheet
  if (isSelected('lots')) {
    const lots = getFirebaseData("lots") || [];
    const lotsSheet = ss.getSheetByName("Lots");
    if (lotsSheet) {
      lotsSheet.clearContents();
      const rows = [["Lot_ID", "Product_ID", "Cost", "Price_A", "Price_B", "Price_C", "Initial_Qty", "Remaining_Qty", "Created_At", "Note"]];
      lots.forEach(l => {
        rows.push([
          l.lot_id, l.product_id, l.cost || 0, l.price_a || 0, l.price_b || 0, l.price_c || 0,
          l.initial_qty || 0, l.remaining_qty || 0, l.created_at || "", l.note || ""
        ]);
      });
      lotsSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }

  // 8. Users Sheet
  if (isSelected('users')) {
    const users = getFirebaseData("users") || [];
    const usersSheet = ss.getSheetByName("Users");
    if (usersSheet) {
      usersSheet.clearContents();
      const rows = [["Full_Name", "Department", "Phone", "Email", "Password_Hash", "Role", "Price_Level", "User_Type", "Can_Approve"]];
      users.forEach(u => {
        rows.push([
          u.fullName, u.department, u.phone || "", u.email, u.passwordHash, u.role || "user", u.priceLevel || "A", u.userType || "insource", u.canApprove ? "true" : "false"
        ]);
      });
      usersSheet.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
    }
  }
}

function syncProductsWithMIS() {
  const ui = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  
  // ดึงข้อมูลล่าสุดจาก Firebase กลับมาอัปเดตลง Google Sheets และ Drive JSON ก่อน เพื่อป้องกันการเขียนทับข้อมูลใหม่ด้วยข้อมูลเก่า
  try {
    backupFirebaseToSheets({ targets: ['products', 'machines', 'settings', 'manuals'] });
    backupFirebaseToDrive({ targets: ['mappings', 'lots'] });
  } catch (err) {
    Logger.log("ดึงข้อมูลจาก Firebase ก่อนซิงค์ MIS ไม่สำเร็จ: " + err.toString());
    const response = ui.alert('⚠️ คำเตือน', 'ไม่สามารถดึงข้อมูลล่าสุดจาก Firebase ได้ก่อนการซิงค์ (อาจเป็นเพราะปัญหาการเชื่อมต่อ)\n\nต้องการดำเนินการซิงค์ต่อโดยใช้ข้อมูลที่มีอยู่ในปัจจุบันบน Google Sheets หรือไม่? (คำเตือน: ข้อมูลที่มีการแก้ไขล่าสุดบนระบบเว็บ/Firebase อาจถูกเขียนทับด้วยข้อมูลเดิมใน Google Sheets)', ui.ButtonSet.YES_NO);
    if (response === ui.Button.NO) {
      return;
    }
  }
  
  const prodSheet = ss.getSheetByName("Products");
  let misSheet = ss.getSheetByName("ตั้งค่า MIS") || ss.getSheetByName("คับค่า MIS") || ss.getSheetByName("คลังค่า MIS");
  
  if (!prodSheet) {
    ui.alert('❌ ผิดพลาด', 'ไม่พบแผ่นงาน "Products"', ui.ButtonSet.OK);
    return;
  }
  
  if (!misSheet) {
    // ค้นหาชีตที่มีคำว่า MIS อยู่ในชื่อ (กรณีมีชื่ออื่น)
    const sheets = ss.getSheets();
    for (let i = 0; i < sheets.length; i++) {
      const name = sheets[i].getName();
      if (name.toUpperCase().indexOf("MIS") !== -1) {
        misSheet = sheets[i];
        break;
      }
    }
  }
  
  if (!misSheet) {
    ui.alert('❌ ผิดพลาด', 'ไม่พบแผ่นงานที่เกี่ยวข้องกับ "ตั้งค่า MIS" (กรุณาตรวจสอบว่ามีชีตชื่อนี้ในระบบ)', ui.ButtonSet.OK);
    return;
  }
  
  try {
    const prodRange = prodSheet.getDataRange();
    const prodValues = prodRange.getValues();
    
    const misRange = misSheet.getDataRange();
    const misValues = misRange.getValues();
    
    // สร้าง Map ข้อมูลเพื่อความรวดเร็วในการค้นหา
    // key: Column A (Product ID), value: { colC: val, colE: val }
    const misMap = {};
    for (let i = 1; i < misValues.length; i++) {
      const key = String(misValues[i][0]).trim();
      if (key) {
        misMap[key] = {
          colC: misValues[i][2], // คอลัมน์ C (ดัชนี 2) -> Group
          colE: misValues[i][4]  // คอลัมน์ E (ดัชนี 4) -> Stock Qty
        };
      }
    }
    
    let updatedCount = 0;
    // วนลูปอัปเดต Products (ข้ามหัวตาราง index 0)
    for (let i = 1; i < prodValues.length; i++) {
      const prodId = String(prodValues[i][0]).trim();
      if (prodId && misMap[prodId]) {
        const misData = misMap[prodId];
        
        // คอลัมน์ L (ดัชนี 11 ใน JS) = ดึงจากคอลัมน์ C ของ MIS (Group)
        // คอลัมน์ K (ดัชนี 10 ใน JS) = ดึงจากคอลัมน์ E ของ MIS (Stock Qty)
        const newColLVal = misData.colC;
        const newColKVal = misData.colE;
        
        let rowUpdated = false;
        
        if (prodValues[i][11] !== newColLVal) {
          prodValues[i][11] = newColLVal;
          rowUpdated = true;
        }
        if (prodValues[i][10] !== newColKVal) {
          prodValues[i][10] = newColKVal;
          rowUpdated = true;
        }
        
        if (rowUpdated) {
          updatedCount++;
        }
      }
    }
    
    if (updatedCount > 0) {
      // เขียนข้อมูลที่อัปเดตกลับลงชีต Products
      prodRange.setValues(prodValues);
      
      // สั่ง Sync ไปยัง JSON Drive และ Firebase อัตโนมัติเพื่อให้แอปเป็นปัจจุบัน
      rebuildAndSaveAppDataJson(true);
      
      ui.alert('✅ สำเร็จ', 'ซิงค์ข้อมูลสำเร็จทั้งหมด ' + updatedCount + ' รายการ และซิงค์ขึ้นระบบเว็บไซต์เรียบร้อยแล้ว', ui.ButtonSet.OK);
    } else {
      ui.alert('ℹ️ แจ้งเตือน', 'ไม่พบข้อมูลที่จำเป็นต้องอัปเดต (ข้อมูลทั้ง 2 ชีตตรงกันดีอยู่แล้ว)', ui.ButtonSet.OK);
    }
    
  } catch (e) {
    ui.alert('❌ ผิดพลาด', 'เกิดข้อผิดพลาดในการซิงค์ข้อมูล: ' + e.toString(), ui.ButtonSet.OK);
  }
}
